## 🎯 Overview

The **Cybersecurity Awareness Website** is an educational platform designed to:

- ✅ Educate users about cybersecurity threats and how to protect themselves
- ✅ Provide comprehensive information about cyber threats in Nepal
- ✅ Share links to trusted cybersecurity resources globally
- ✅ Promote safe internet practices and digital literacy
- ✅ Help users understand Nepal's cyber laws and regulations

This website targets a diverse audience including students, professionals, and general internet users who want to learn about staying safe online.

## 📦 Installation & Setup

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML and CSS (if you want to modify)

### Steps to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/cybersecurity-awareness.git
   cd cybersecurity-awareness
   ```

2. **Open in a browser**
   - Simply double-click `index.html` to open in your default browser
   - OR use a local server for better performance:

   ```bash
   # Using Python 3
   python -m http.server 8000

   # Using Python 2
   python -m SimpleHTTPServer 8000
   ```

3. **Access the site**
   - Open `http://localhost:8000` in your browser
